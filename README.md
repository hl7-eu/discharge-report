# discharge-report
HL7 Europe Discharge Report FHIR Implementation Guide

This guide generalises the [HL7 Europe Hospital Discharge Report (HDR) FHIR IG](http://hl7.eu/fhir/hdr) to cover any kind of discharge report, as defined by the Xt-EHR EHDS `EHDSDischargeReport` logical model.

Web-build: https://build.fhir.org/ig/hl7-eu/discharge-report/

Issues: https://github.com/hl7-eu/discharge-report/issues
